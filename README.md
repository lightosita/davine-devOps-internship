# Davine DevOps Internship — Week 2: Git & GitHub Practice

## Overview
Practical exercises completed for Week 2 of the Davine Technologies DevOps Internship, covering Git fundamentals, GitHub collaboration, branching, merging, and rebase.


## What's in this repo
- `notes.md` — practice notes on Git commands
- `hello.sh` — sample script committed via feature branch workflow
- `feature.txt` — created on an initial rebase practice branch (`rebase-practice`) that turned out to already be up to date with main, since no divergence existed yet at branch-creation time
- `feature2.txt` — created on a second rebase practice branch (`rebase-practice2`) that correctly demonstrated a real rebase, after intentionally diverging from main first


## Skills demonstrated
- Git installation & configuration
- Staging, committing, and pushing changes
- Branch creation and merging
- Rebase to maintain linear history
- Resolving real authentication issues (token-based auth over HTTPS)
